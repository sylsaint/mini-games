# 《逃出马王堆》地下发现

每完成一格仍固定获得 1 游戏金币。额外发现最多一项：食物（1 包共 3 份，沿用拉绳补给）、徒手的 1 级小人，或一种可在背包中兑换的宝物。救到的人不提高付费招募价；队满时在地表等待。不改变原有挖掘工期、合成和工具。宝物以真实马王堆出土器物为原型，但地点、概率和兑换价均为游戏设定，不表示文物的真实价格或相对价值。
