# 文物侦探局 01：错放的封签

## 目标与约束

不是按提示点完的低龄流程，而是面向小学中高年级的短篇解谜。有失败假设，没有死亡、体力、强制倒计时或付费。本作的“难”来自互相依赖的证据、实验设计和视觉对照，不来自手速、长篇阅读或把小按钮点很多遍。人、封签、样布和位置都是游戏虚构。真实原型为西汉马王堆一号墓的 49 克直裾素纱单衣（湖南博物院研究馆员资料见游戏）。

## 推进与难度曲线

1. **勘查**：从交接档案找三种独立参照，再到工坊用同一工具检验四包候选。误判有可观察的反证；三种属性里每个干扰物各缺一种，只看任意两种都不够。上光时辨底纹、沿尺辨末端曲直、转印识别形状和点数。笔记有对照表，减少来回翻找。
2. **计量**：砝码有限，不显示未知衣重或指定算法。玩家必须把两个不平衡实验与一个平衡实验记入证据；能倒序寻找，调整右盘不会清空实验册。错误允许重试；提示逐层提供方法。
3. **复原**：一块固定样布、三块候选，先比线型和方向，再移动样片对准三处接缝。文字线头数据是无障碍备用；不以颜色作为唯一辨别维度。最终选两句证据足以支持的展签，区分「看着透」和「称出重量」。
4. **反馈与保存**：完成一阶段建立本地检查点，刷新后可继续或重开；单个房间里未提交的记录不跨刷新。已发布旧版的存档键不覆盖。稀有发现不绕过三类必验证据。

## 视觉与交互

档案蓝绿与沈金、证物工作台有纸与漆器质感；找物场景、印记和纺织样品使用原创轻量 SVG。发光是观察反馈，不圈出正确选项。拖动有点击或键盘替代；动态反馈写入观察记录，避免只能靠视觉读取。画面不复刻真实墓室布局。

## 验收

- 忽略任何一类证据不能直接推进；错误假设有明确反证，不清空进度。
- 称平不等于完成；必须留有两侧比较，且可在不同顺序完成。
- 错方向、错高低、过度推断分别收到针对性反馈。
- 桌面与两种手机浏览器配置可通关，刷新后重开证据和展柜；入口和旧《逃出马王堆》都在。
- 首发后若再迭代，优先观察孩子不读提示时会不会找参照、能否解释排除某包的理由、在哪一步卡住；不能用自动化通关时间当真实玩家难度。
