# 工程化收尾与边界

基线：`4acd3f985d0a7a9c46a4d007a2b7aa462eaf94dd`。本次不新增私人内容，也不更改历史存储 key、业务 URL 或题目规则。

## 基线复核

13 个历史业务页面已由 SvelteKit 领域组件渲染。第一次迁移仍有以下不足：24 点视图部分由原生 DOM 控制；旅游依赖 document 点击委托；共享 storage 没有业务消费者；config 只是空包；定制 404 没有进入产物。原版离线下载是有意保留的兼容功能，不属于在线页替代实现。

修改前 `npm run check` 已通过：85 个单元测试、Svelte 零错误/警告、13 个业务路由构建。原发布版本 CI/CD 的浏览器基线为 116 通过、1 个桌面触控测试按条件跳过。

## 实施步骤

1. 补齐共享配置的真实消费者：构建和校验共同使用业务路由、旧地址别名、安全响应头和页面体积预算。
2. 从 Svelte 组件生成自定义 404 页面，保留直接 `/404.html`，Cloudflare 和本地静态服务对未知 URL 返回 404，而不是首页 200。
3. 共享存储封装与业务接入；验证损坏数据、存储不可用和已存进度，读取不能写回默认值。
4. 24 点的视图状态和用户命令转入 Svelte 边界；保留合理的浏览器能力适配，不改变规则和声音。
5. 旅游组件使用显式回调和状态；不改变刚修复的语音选择/首次播放算法。基础 UI 仅在不破坏原布局和可访问性的地方复用。
6. 完整单元/类型/构建/跨浏览器回归，PR CI 成功后通过原 GitHub → Cloudflare Pages CD 发布。最终记录以实际完成的检查为准。

## 保留的合理边界

- Web Speech、AudioContext、打印、下载、视口图片观察、焦点和 pointer capture 仍需浏览器 API；不将“没有 DOM API”当作工程质量指标。
- 几何 SVG 来自仓库内受控绘图函数；不是用户 HTML，也不是嵌入旧整页。以后可进一步拆为 SVG 组件，但不是本次功能完整性的必要条件。
- 旅游和 24 点的原版独立 HTML 离线导出继续保留，明确区分在线拆包与离线下载。
- 真实 iOS 的中文语音音色/可播放性仍需实体设备确认；模拟器测试不替代真人听感。

## 本地验证记录

- `npm run check`：103 个单元测试全部通过；Svelte 0 错误、0 警告；14 个路由（13 业务 + 404）、76 个资源构建校验通过。
- 本地 HTTP 直接检查：浅层和多层未知 URL 返回 404，`/404.html` 返回 200，均含定制文案与根路径资源引用。`kit.paths.relative=false` 避免错误页位于任意深度时丢失 CSS/JS。
- 语文和数学报告的全部模板正文/CSS 与本次基线逐字相同，仅调整存储调用。
- 本机浏览器执行仍受 `socket() EPERM` 环境限制，跨浏览器验证必须由 GitHub CI/CD 实际执行。上述本地结果不能替代浏览器通过结论。
