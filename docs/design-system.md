# 设计系统

设计原则：儿童友好但不幼稚，大触控目标、暖白纸感、森林绿主色、紫色/橙色点缀；正文 16–18px，长内容保持舒适行宽。旅游、教育、游戏保留自身辨识度，不将全部页面变成后台仪表盘。

基础组件集中 packages/ui，以 shadcn-svelte 的源码可维护模式组织。需要时采用 Bits UI 的键盘、焦点与状态原语。统一 Button、Card、Dialog、Tabs、Progress 等，不加载未使用组件。

组件使用明确文字和 accessible name，不能仅靠颜色提示对错。保持 focus-visible、44px 左右触控区域、prefers-reduced-motion、对话框退出焦点；图片文字替代、标题层级与打印规则都属于验收。

字体沿用本地系统中文字体，不为视觉效果额外下载大型中文字体。领域 CSS 在容器内隔离。提供基础 token，但不强行全站深色模式，以免插画和教育图形失真。

数学试卷列表使用 `@yoyo/ui/card` 与支持链接的 `@yoyo/ui/button`，纵向留出 16–24 px 组间空白。新试卷页面沿用「线与角」的浅色画布、纸白卡片和森林绿操作按钮；确认交卷或重做使用 `@yoyo/ui/dialog`，Esc 或取消后焦点回到触发按钮。题目专用图形继续在教育包中实现，不定义另一套基础按钮样式。
