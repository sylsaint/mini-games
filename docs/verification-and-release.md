# 验证与发布

## 必须执行
1. 原始内容、题库、图片署名快照/数量核对。
2. 旧 localStorage fixture、坏数据、禁用存储；默认状态不得覆盖已有记录。
3. 单测、Svelte/TypeScript 检查、静态构建、Playwright Chromium 和 WebKit。
4. 移动布局、键盘、焦点、打印、减弱动态；返回/前进和重复操作。
5. 语音首次点击、停止重播、页面退出；离线 HTML 导出后重新打开。
6. 首页不得请求其他领域题库与图片，隐藏景点图片不加载，离线代码只在导出时加载。
7. 远端准确提交、CI、CD、生产 build.json 与关键线上路径核验。
