# 四上第二单元：线与角互动卷

## 范围与隔离
- 新路由 `/learning/math/lines-and-angles/`，入口位于数学学科页。
- 20 道正卷题，每题 5 分；4 道较难选做不计入 100 分。原创练习，非官方试卷。
- 独立 JSON 题库与存储键 `yoyo-math-lines-angles-v1`；不改综合卷题库、综合卷答案或几何探险岛进度。
- 沿用共享的数字规范化、正卷评分、进度格式校验及 `@yoyo/storage`；保留不计时、跳题返回、刷新续做、交卷前不显示解析、确认交卷和独立重来流程。

## 图形与交互
- 几何图由仓库内 Svelte SVG 声明式渲染，不依赖外部图片。
- 图形辅助线的长度不代替题设；推理图标注“示意图，按题设推理”，不把解出的未知量标在图上。
- 量角题真实显示同圈/双圈刻度。画角以左向水平射线为始边，在上半平面画 60°；触摸点选/拖动与键盘、整数输入均可操作。不采用模糊误差给分，精确控件保证可完成。
- 角的大小不随屏幕缩放改变；响应式 viewBox、文字标签和无障碍描述要共同验证。

## 验收
1. 题目 ID 唯一、20+4 数量、100 分、选项唯一、关键角度独立算式核对。
2. 所有需看图题有 SVG；角的方向、箭头、顶点和刻度正确，无提前答案。
3. 桌面 Chromium、iPhone WebKit、Android Chromium：跳题、返回、刷新、不同卷记录隔离、交卷/重来确认、测量/画角和布局。
4. 与综合卷第17题补图合并后的 main 集成，跑全部旧回归而非只跑新卷。
5. 沿用 GitHub PR CI → main CD → Cloudflare Pages，校验部署SHA、资源哈希及生产互动。不创建新站点或后端。
